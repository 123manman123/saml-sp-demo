SAML 2.0 服务提供者演示

SAML SP Demo for NGIAM IDP

项目说明

本项目是一个 SAML 2.0 服务提供者（SP）演示项目，用于对接 NGIAM IDP 实现单点登录。

配置信息

SP Entity ID
ACS Location
IDP Entity ID
IDP SSO URL
SP Metadata URL

操作

SAML 登录 查看 SP 元数据

认证流程

  1. 点击"SAML 登录"按钮
  2. 系统检测到未登录，重定向到 IDP
  3. IDP 进行用户认证
  4. IDP 生成 SAML Assertion 并 POST 回 SP
  5. SP 验证签名，建立会话，跳转到用户信息页
