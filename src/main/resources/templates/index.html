接入说明

这里不是一张简单配置表，而是一条完整的调试路径。

你可以先核对 SP 与 IdP 的关键地址，再导出 Metadata 完成信任配置，最后直接跳转到受保护资源页面验证整条认证链路。

Flow

认证流程

  1. 01

    进入受保护资源

    点击“发起 SAML 登录”后访问 `/user` 页面，系统会检测当前会话状态。

  2. 02

    自动跳转至 IdP

    若尚未登录，Spring Security 会将认证请求重定向到 NGIAM IdP。

  3. 03

    用户完成身份验证

    IdP 验证通过后生成带签名的 SAML Assertion，并通过 HTTP POST 返回 SP。

  4. 04

    SP 校验并建立会话

    应用验证签名和断言内容，建立本地安全上下文并展示用户属性。
